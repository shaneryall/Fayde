    Python API¶

    For examples of how to use the fayde package, see Use Fayde from Python.

    fayde ¶

    Fayde astrometric plate solver.

    Open a :class:Solver once (catalogue and pattern indexes), then call :meth:Solver.solve, :meth:Solver.verify or :meth:Solver.refit per frame. Each returns the report fayde solve, fayde verify or fayde refit prints, as a dict.

    Conventions:

    • Input x, y are 0-based (NumPy / Astropy) unless origin=1 (FITS).
    • Report pixel fields (pairs[].x, predicted_x, covariance.crpix_fits, wcs_cards) are FITS 1-based, as in the command-line report.
    • Angles are degrees, the scale arcsec/px, the deadline seconds.

    Options (keyword arguments), the same as the command line's:

    width, height, ra, dec, radius, pointing_sigma, scale, scale_sigma (fraction), roll, roll_sigma, roll_max, parity ("negative"/"positive"), trail_length, trail_angle, epoch (Julian year), deadline, max_hypotheses, max_sip_order, pixel_error, accept_log_odds, no_priors, no_pointing, no_header_wcs, search_outside_pointing, relax_priors_on_failure, header, instrument, origin.

    header is a dict, a list of 80-character cards, or an astropy.io.fits.Header. instrument is a profile dict or the path of a profile JSON file.

    FaydeError ¶

    Bases: RuntimeError

    The solver failed (invalid request, catalogue error). report holds the JSON report, with "error": True and reason, as the command line prints it.

    Solver ¶

    A UCAC4 catalogue and pattern indexes, opened once and reused.

    ucac4 is the UCAC4 directory (holding u4b/, optionally u4i/); by default the FAYDE_UCAC4 environment variable. indexes are the .fidx files used by :meth:solve. Thread-safe: the GIL is released while solving.

    solve(x, y, **options) ¶

    Solve a source list. Returns the report; report["solved"] says whether it solved (an abstention has reason, best_log_odds, hypotheses_tested, search).

    solve_detection(detection, **options) ¶

    Solve the sources of a :func:detect report: their 1-based positions, fluxes, errors, star probabilities and truncation, and the stars' trail when the report found one (unless trail_length and trail_angle are given). Takes :meth:solve's options; pass the image's header for its priors.

    solve_image(image, **options) ¶

    Find the stars in an image and solve: image is a FITS path, a 2-D array or an Astropy HDU. The image's header gives the priors unless header is passed. Takes :meth:solve's options and :func:detect's; the report adds detection.

    verify(x, y, wcs, **options) ¶

    Check a WCS (dict, cards or astropy Header) against the catalogue, unchanged.

    refit(x, y, wcs, **options) ¶

    Re-fit a WCS against the catalogue.

    stars_at(wcs, x=None, y=None, *, ra=None, dec=None, sigma_px=None, sigma_arcsec=None, **options) ¶

    Is there a catalogue star here? For pixel positions x, y and/or sky positions ra, dec (degrees) under wcs, the nearest catalogue stars at the epoch, with separation, combined 1σ, p_consistent (Rayleigh tail: chance of this offset or more if the position is the star), p_chance (chance that some star lies this close to an arbitrary position) and consistent.

    Options: epoch, header (for the epoch), pixel_error (default pixel 1σ), wcs_sigma_arcsec, search_radius_arcsec (default 30), max_stars (default 3), origin. Positions come back in input order, pixels first.

    detect(image, **options) ¶

    Find stars in an image: a FITS path, a 2-D array (row 0 = FITS row 1) or an Astropy HDU.

    Options: fwhm (px; default measured), detect_threshold (σ of a peak, at least 1.5; default: the level that lets one noise peak through per frame, about 5), saturation and gain (default: the header's SATURATE, GAIN/EGAIN), max_sources (default 2000), trail_angle (degrees from +x towards +y: the expected direction of star trails, to choose among directions), no_trails (measure every star as a point, even when the stars are trails) and header (dict or cards, for an array). Returns the report fayde detect prints: settings, background, noise, mode ("points", "trails", "kernel", or "refused") with census, trail, and kernel, sources (the stars, with FITS 1-based x, y, sigma_px, flux, p_star and class), streaks (ends, angle, width, flux) and rejected (hot pixels, cosmic-ray hits, anything on a streak, point-like objects in a trailed frame).

    To solve the sources, pass the report to :meth:Solver.solve_detection; its positions are 1-based, which :meth:Solver.solve takes only with origin=1.
